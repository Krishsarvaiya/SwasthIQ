# Security policy

If you find a security problem in the SwasthIQ website, please report it
privately to krishsarvaiya2005@gmail.com with the subject "SwasthIQ security report".
Do not open a public issue.

Please include the page or URL, steps to reproduce, and the impact you see.
We will reply as soon as we can. Please do not access other people's data,
run denial-of-service tests, or test the app's real user accounts.
There is no paid bug bounty at this time.
